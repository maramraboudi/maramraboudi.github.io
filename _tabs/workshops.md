**Workshop 1 · Web Application Security**

## Introduction to Web Penetration Testing with Burp Suite

My first cybersecurity workshop was an introduction to web application security and **Burp Suite**. I led a hands-on session for students, starting with how web requests move between a browser and an application, then showing how Burp Suite can help security testers inspect that traffic in an authorized testing environment.

The goal was to make web penetration testing feel less mysterious: understand the request first, then learn how to observe, question, and test it responsibly.

<img class="portfolio-image" src="/assets/img/workshops/burp-suite-workshop-wide.jpg" alt="Presenting the Burp Suite workshop to students">

### What we covered

- The purpose and ethics of web penetration testing
- How HTTP requests and responses work
- Installing and configuring Burp Suite Community Edition
- Using FoxyProxy to route browser traffic through Burp Suite
- Intercepting and examining requests with Burp Proxy
- An introduction to Repeater, Intruder, Decoder, Comparer, and Sequencer
- Reading HTTP headers, cookies, and session-related data
- Comparing Burp Suite with tools such as OWASP ZAP and Caido

### Hands-on learning

After the introduction, I worked with attendees as they configured their own environments and used Burp Suite to inspect web traffic. The practical part focused on observation and safe experimentation: seeing what a browser sends, recognizing headers and cookies, and using Burp's tools to better understand application behavior.

**Workshop 2 · Cryptography Fundamentals**

## Cryptography Basics

I led a **Cryptography Basics** workshop organized by **EagleDefenders** and hosted by the **IEEE SESAME Student Branch**. The session introduced students to the building blocks behind secure communication and how they support the systems we use every day.

We explored **symmetric and asymmetric encryption, hashing, and random number generation** through clear explanations and interactive, hands-on exercises. Participants had the opportunity to work with these concepts, understand how they are used, and consider how they contribute to designing and evaluating secure systems.

The workshop reflected EagleDefenders’ mission to make cryptography practical and approachable for students and crypto enthusiasts. I enjoyed helping participants build a stronger foundation for thinking about how we protect the digital world.

**Workshop 3 · Digital Forensics**

## Disk Analysis with Autopsy

I led an introductory workshop on **disk forensics** using **Autopsy**, a digital forensics platform. We explored how investigators can examine a disk image, navigate the evidence found in a case, and use file and activity details to build a clearer picture of what happened.

Participants followed a guided, hands-on investigation and worked through a practical challenge using the evidence presented in Autopsy. The exercise introduced a basic forensic workflow: review the available artifacts, follow clues in the data, and use the findings to answer the challenge questions.

The session was designed to make digital forensics approachable for beginners and to show how careful evidence analysis can support an investigation.
